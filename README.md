# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior using **Python, SQL, and Power BI**.

The goal is to understand customer purchasing patterns, sales performance, customer segments, and other business factors that can help a company make better decisions.

The project follows a complete **Data Analytics workflow**, starting from raw data preparation and ending with an interactive Power BI dashboard and business recommendations.

---

## 🎯 Project Objectives

* Analyze customer purchasing behavior.
* Clean and prepare the raw dataset.
* Perform exploratory data analysis using Python.
* Perform business analysis using SQL.
* Create an interactive Power BI dashboard.
* Identify important business insights.
* Provide actionable business recommendations.

## 🚀 How to Run This Project

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
```

### 2. Open the Project

Open the project folder in **VS Code**.

### 3. Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4. Run Python Analysis

```bash
python data_cleaning.py
```

Run the remaining Python scripts according to the project workflow.

### 5. Run SQL Analysis

Open the SQL file in your preferred database environment and execute the queries.

### 6. Open Power BI

Open the `.pbix` file using **Power BI Desktop** to explore the interactive dashboard.
